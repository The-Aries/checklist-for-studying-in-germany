# APS Post-Graduation CV Template Specification

## Purpose

APS 2026-09 requires applicants who graduated more than one year earlier to submit a German- or English-language tabular CV describing the period after graduation.

APS does not provide a project-specific editable template in the sources used for this milestone, so the repository should provide a **clearly non-official convenience template**.

## Public file

`templates/aps-post-graduation-cv-template.docx`

The APS conditional CV checklist row should expose a direct download link when the row is applicable. It may remain visible but labeled “仅在毕业超过一年时使用” when not applicable.

## Required disclaimer inside the document

Place this near the top:

**Unofficial convenience template / 非 APS 官方模板。请始终以 APS 最新官方要求为准。**

## Suggested structure

Title:

**Post-Graduation Curriculum Vitae**

Basic fields:

- Full name
- Bachelor graduation date (orientation field for the timeline; do not describe it as an APS-mandated form field)

Main table:

| Period (MM/YYYY–MM/YYYY) | Activity / Status | Institution / Employer / Location | Notes |
| --- | --- | --- | --- |
| | | | |
| | | | |
| | | | |
| | | | |
| | | | |

## Guidance text

Keep guidance concise:

- complete the timeline from bachelor graduation to the present;
- use German or English;
- add/delete rows as necessary;
- do not fabricate activities to fill gaps;
- this template is not an APS-issued form.

Do not add requirements such as a photo, date of birth, marital status, nationality, place/date/signature fields, or an exhaustive personal profile unless a future official source explicitly requires them.

## Maintainability

If creating the DOCX from a source format/script, commit that source too so future maintainers can reproduce it.

The generated DOCX must not contain macros, external embedded objects, tracking pixels, or personal sample data.
